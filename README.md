# limorsinay.com

Source for [limorsinay.com](https://limorsinay.com), the personal site of Limor Sinay: fractional CRO advising on go-to-market for seed and Series A companies, speaking, and writing on AI for GTM.

## About the site

- Plain HTML and CSS. No framework, no build step.
- Pages: home, services, about, and a series-based blog.
- Hosted on GitHub Pages from the `main` branch. Pushing to `main` redeploys the site.

## Run locally

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000.
